KNOWLEDGE UPDATE — three-instrument fusion is IMPLEMENTED (read this first)
============================================================================

The prototype now runs all three Chandrayaan-2 instruments end to end, plus
the NASA LRO NAC reference. Older sections below that call TMC-2/IIRS a
"stretch goal" or "future work" are superseded by this note.

- Reference libraries: backend/tmc.py indexes 48 Chandrayaan-2 TMC-2 DTM
  products straight from the PRADAN bundle TARs (labels + browse thumbnails
  only), backend/iirs.py indexes the 2 IIRS 256-band spectral records from
  the product ZIPs, backend/lroc.py keeps the 8 NASA LRO NAC strips. Every
  scene gets the nearest product of each instrument ranked by great-circle
  footprint distance + coarse NCC, registered onto the scene grid.
- Layer system (02 TERRAIN 3D, GET /layers/{id}): HEIGHT (shape-from-shading,
  photometric approximation), OPTICAL (radiance draped on the mesh),
  METRIC (TMC-2 stereo DTM read as true measured heights in meters, int16
  with -32768 nodata), MINERALS (IIRS cube classified by continuum-removed
  band depths at 1 um / 2 um / 3 um - pyroxene-rich, olivine-rich,
  feldspathic, mixed, OH/H2O classes; heuristic band-depth method, SAM
  against RELAB/M3 lab spectra remains future work), and SFS-METRIC
  validation (both fields normalized to [0,1]: Pearson r + normalized MAE;
  r near 0 is reported honestly for shaded-relief input).
- Where mutual information is used NOW: reported as the cross-modal
  similarity statistic for the TMC DTM-shaded-relief vs OHRC-panchromatic
  and IIRS-spectral vs panchromatic reference pairs (Problem 6 applied,
  not reserved).
- Match window additions: multi-instrument reference strip (NASA + nearest
  TMC-2 + nearest IIRS thumbnails with distances), and a one-click
  SYNC SCENE -> UPLOAD button that carries the matched scene's image into
  the upload window.
- ONNX descriptor retrained locally: triplet ranking accuracy 0.850
  (gate > 0.5), export verified by onnxruntime.
- Scene ladder: Level 1 CH-2 TMC demo product, Level 2 Tycho synthetic,
  Level 3 CH-2 OHRC real scene, Level 4 TMC-2 metric DEM scene
  (tmc2_metric_demo), Level 5 IIRS mineral scene (iirs_mineral_demo),
  Level 6 OHRC polar scene (ohrc_polar_20211222, -84.22 deg, 312.28 degE) -
  the FIRST scene with all four instruments stacked: OHRC source + REAL
  RANSAC-verified NASA NAC reference (M1263400700LC) + TMC-2 METRIC layer
  + IIRS MINERALS layer + SFS-METRIC validation (5/5 layers).

DEPLOYMENT UPDATE — the project runs LIVE on free cloud hosting
================================================================
- Live URL: https://sih26166-backend.onrender.com (Render free web service,
  Blueprint from render.yaml, Python 3.11, 512 MB RAM). The SAME service
  serves the frontend, the API, the ONNX descriptor and the scene caches -
  one link, nothing else to explain.
- The 29 GB of raw rasters live in PUBLIC Kaggle datasets owned by
  rounakmukherjee22 (lro-nac-polar, ch2-iirs-tmc2-data,
  final-kaggle-dataset, ch2-tmc2-derived-part-1..4, ch2-tmc2-collection,
  ch2-tmc2-dtm-collection, ch2-ohrc-iirs-collection,
  ch2-tmc2-iirs-combined-dataset, ohrc-polar-*). KAGGLE_TMC_DATASET /
  KAGGLE_IIRS_DATASET accept COMMA-SEPARATED dataset lists and the fetcher
  (backend/kfetch.py) searches every listed dataset per product file, so
  scattered files are found regardless of which dataset holds them.
- RAM diet for the 512 MB free tier (peak measured 1244 MB -> 275 MB):
  ONNX runtime arena disabled + single-thread session, learned keypoints
  capped at 400, patch embedding streamed in 128-patch batches, and
  multi-GB TMC-2 DTM windows are read with tifffile memmap / per-strip
  byte-range reads (never a full 1.5-gigapixel decode).
- Portability: registry scene dirs are remapped to the running checkout at
  load time, so the stale-scene cleanup can never wipe scenes on a host
  whose paths differ from the machine that baked them.
- Honest-labeling rule preserved online: Level 6's exact DTM window is a
  measured polar no-data gap, so its METRIC layer uses the NEAREST fully
  valid DTM window (~2.9 km) and says so on the layer note; scenes without
  instrument coverage report verified no-coverage instead of showing
  another region's data.
- Azure option (hybrid Kaggle + Azure): an Azure **Container App** hosts the
  same single container (deploy/Dockerfile, target port 7860) on a
  SCHEDULE: min-replicas 1 from 07:00-19:00 IST and 0 (scale-to-zero, ~$0)
  overnight, driven by the azure-schedule GitHub cron (01:30/13:30 UTC);
  image ships from Docker Hub via the docker-build workflow (no ACR cost).
  Kaggle remains the data plane (per-file multi-dataset fetch on new
  uploads); overnight wake is 1-3 min since all scene caches ship in the
  image. ~$14/mo at 12h/day after the free consumption grants (~7 months
  from the student credit); Render (free) stays the fallback link.
  Runbook: DEPLOYMENT.md section 8.

TERRAIN LAYER KNOWLEDGE (for narration):
- HEIGHT-SFS: linearized-Lambertian shape-from-shading from the mission sun angles; a photometric approximation (non-metric), stated on screen.
- OPTICAL: the raw radiance image draped on the SFS mesh.
- METRIC-TMC-2: MEASURED stereo-photogrammetric heights from the Chandrayaan-2 TMC-2 DTM, co-registered to the scene coordinates; fetched per-file from the project Kaggle datasets.
- MINERALS-IIRS: 256-band IIRS cube -> continuum-removed 1um/2um/3um band depths -> pyroxene/olivine/feldspathic/mixed/OH-H2O classes with legend.
- SFS-METRIC: per-vertex difference between SFS and the metric DEM with Pearson r and MAE - the measured validation of the reconstruction.
- Scene ladder: L1 TMC demo baseline; L2 Tycho synthetic stand-in (labeled); L3 OHRC equatorial cross-mission vs NASA; L4 TMC-2 metric + validation; L5 IIRS minerals; L6 OHRC polar 4-instrument fusion (OHRC + real NASA NAC M1263400700LC + TMC-2 metric + IIRS minerals).
- Level 6 METRIC uses the nearest fully-valid DTM window ~2.9 km from the scene center (measured polar no-data gap; labeled). A clamped height plateau at the DTM no-data boundary (zero-variance raster-max artifact) is detected and inpainted from surrounding valid terrain - reported in the layer note.
- Crater lat/lon: local tangent-plane approximation from the label footprint center (north-up, lunar radius 1737.4 km, lon scale x cos|lat|).
